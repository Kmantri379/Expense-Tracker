# Expense Tracker (Java + XML)

A simple Android college project with four screens:
1. Home — total expenses and navigation buttons
2. Add Expense — saves expense name, amount and category
3. View Expenses — lists saved expenses; tap an item to delete it
4. About — describes the app and Android concepts used

## Concepts demonstrated
- Explicit Intents to open Activities
- Java Activities and XML layouts
- SQLite database persistence
- Basic input validation

## Open in Android Studio
1. Extract this ZIP to a local folder such as `C:\AndroidProjects\ExpenseTracker Project` (preferably outside OneDrive).
2. Open the extracted project folder in Android Studio.
3. Let Gradle sync finish, then click Run.
4. If Android Studio asks for an SDK location, select the SDK installed on your computer.

Generated `build` folders and machine-specific `local.properties` are intentionally excluded.
